# MydigitalPlayground

Questo è il mio progetto personale, uno spazio in cui imparo a programmare facendo pratica.
Qui raccolgo esperimenti, esercizi e prove di codice scritti da me: il codice non viene generato con l’aiuto dell’intelligenza artificiale.

## Avviare il progetto

Installa le dipendenze e avvia il progetto con questi comandi:

```bash
npm install
npm start
```
